# SpendSmart

A private expense tracker that reads your bank SMS, UPI and receipts — daily allowance, rent shield and AI forecasts, all on device.

## Getting Started

```bash
npm install
npm run dev
```

## Features

- **Smart Import** — paste a bank SMS or UPI alert and watch it become a categorized transaction
- **Daily Allowance** — know exactly what is left to spend after rent and bills
- **AI Advisor** — reads your week, week vs week, and tells you your goal runway and top leak
- **Rent Shield** — rent and fixed bills are locked before anything else
- **Ghost Savings** — skip an impulse buy and watch that money hop straight into savings
- **Subscription Hunter** — recurring charges you never use get flagged
- **Privacy First** — parsing runs locally on your device

## Tech Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- GSAP animations
- Lucide icons
- @fontsource (Playfair Display + Inter)
